# ✈️ Unified English–Tamil Multilingual Airline Sentiment Analysis

A multilingual sentiment analysis system that classifies airline-related tweets in **English**, **Tamil**, and **English-Tamil code-mixed** language into three sentiment categories using a single unified transformer model.

> **One model. Three languages. No translation at inference time.**

---

## 📌 Problem Statement

The original project (https://github.com/Ilhamlafeer/Airline_Sentiment_Analysis_Using_BERT) performs English-only airline sentiment analysis using `bert-base-uncased`. While effective for English tweets, it cannot handle Tamil or code-mixed input which is common in multilingual social media contexts.

This extension builds a **unified multilingual sentiment classifier** that uses **one model** to understand and classify:

| # | Language | Example |
|---|----------|---------|
| 🇬🇧 | **English** | *"The flight was delayed again! Terrible service."* |
| 🇮🇳 | **Tamil** | *"விமான சேவை மிகவும் மோசமாக இருந்தது!"* |
| 🇬🇧🇮🇳 | **English-Tamil Code-Mixed** | *"இந்த flight service ரொம்ப மோசமாக இருந்தது."* |

The system works directly on the original input language. **No translation is performed during inference.**

---

## 🧠 Classification Model

### IndicBERT-v3-270M (Primary)

```
ai4bharat/IndicBERT-v3-270M
```

IndicBERT-v3 is a bidirectional encoder model based on the Gemma-3 architecture, trained using curriculum learning across 23 Indic languages. It supports both English and Tamil natively.

A 3-class sequence classification head is added for sentiment prediction:

| Label | Sentiment |
|------:|-----------|
| 0     | Negative  |
| 1     | Neutral   |
| 2     | Positive  |

### Alternative Model (XLM-RoBERTa)

The architecture supports `FacebookAI/xlm-roberta-base` as an optional comparison model:

```bash
python scripts/train_multilingual.py --experiment C --model FacebookAI/xlm-roberta-base
```

The project uses the [Twitter US Airline Sentiment Dataset](https://www.kaggle.com/datasets/crowdflower/twitter-airline-sentiment) (`Tweets.csv`) containing **14,640** airline-related tweets.

### Original Dataset Distribution

| Sentiment | Count  | Percentage |
|-----------|-------:|------------|

| Positive  | 2,363  | 16.1%      |

- Dropped **213** duplicate tweets
- Final dataset: **14,427** unique tweets
- Tweet length: 2-36 words (mean: 17.7 words)

## 🌐 Translation Pipeline

Tamil translations are generated using **AI4Bharat IndicTrans2**:

```
ai4bharat/indictrans2-en-indic-dist-200M
```

- Source: `eng_Latn` (English) → Target: `tam_Taml` (Tamil)
- **14,427** tweets translated in **~23 minutes** on a Tesla T4 GPU (~10.5 tweets/sec)
- Batch size: 32

### Translation Pipeline Features

- Preserves @mentions, #hashtags, URLs, and emojis
- Translates natural language content only
- Caches results for resumability with periodic checkpoints
- GPU/CPU auto-detection

### Sample Translations

| English | Tamil | Sentiment |
|---------|-------|-----------|
| *@USAirways I've been on hold for 40 minutes just to get a receipt...* | *@USAirways ஒரு ரசீது பெறுவதற்காக நான் 40 நிமிடங்களாக நிறுத்தி வைக்கப்...* | Negative |
| *@AmericanAir Thank you for the info! Changes need to be made over the phone, cor...* | *@AmericanAir தகவலுக்கு நன்றி! தொலைபேசியில் மாற்றங்கள் செய்யப்பட வேண...* | Neutral |

> **Important:** Machine-translated Tamil tweets are explicitly marked as `source=machine_translation`. They are not claimed to be naturally occurring Tamil text.

## 🔀 Code-Mixed Generation

Synthetic English-Tamil code-mixed tweets are generated by mixing words from English and Tamil versions of the same tweet:

- **7,213** tweets selected (50% of pairs)
- **6,940** code-mixed tweets generated (273 skipped - too short or single-language)
- Swap probability: 30% per word
- Domain terms (airline, flight, delay, etc.) kept in English

### Sample Code-Mixed Tweets

|---------------------|---------------------|-----------|
| *@JetBlue the departure time keeps getting Late Flightr...* | *@JetBlue departure time keeps ஃப்ளைட்டர் பெறுகிறது...* | Negative |
| *@AmericanAir I need an answer why we can't get into Wichita Falls...* | *@AmericanAir விசிட்டா an answer ஏன் we can't என்பதற்கு என...* | Negative |

## 🔬 Methodology

```
English dataset (Tweets.csv, 14,640 tweets)
    │
    ▼
Preprocessing (drop 213 duplicates → 14,427)
    │
    ▼
Stratified Split (train/val/test)     ← BEFORE augmentation
    │
    ├── English tweets (source=original)
    │
    ├── Tamil translations (IndicTrans2, source=machine_translation)
    │
    └── Code-mixed variants (source=synthetic_codemixed)
    │
    ▼
Unified Multilingual Dataset (35,790 records)
    │
    ▼
IndicBERT-v3-270M + Classification Head
    │
    ▼
Per-language Evaluation (EN / TA / EN-TA / Combined)
```

### Cross-Experiment Comparison Summary

| Experiment | Model | EN Acc | EN F1 | TA Acc | TA F1 | CM Acc | CM F1 |
|------------|-------|-------:|------:|-------:|------:|-------:|------:|
| A (EN only) | IndicBERT | 0.838 | 0.786 | 0.781 | 0.724 | 0.783 | 0.706 |
| B (EN+TA) | IndicBERT | 0.836 | 0.778 | **0.811** | **0.752** | 0.779 | 0.696 |
| C (EN+TA+CM) | IndicBERT | 0.818 | 0.765 | 0.801 | 0.738 | **0.791** | **0.721** |
| C (EN+TA+CM) | XLM-R | **0.835** | **0.784** | **0.814** | **0.756** | **0.800** | **0.725** |

### Key Findings

1. **Zero-shot cross-lingual transfer works**: Even with English-only training (Exp A), IndicBERT achieves ~78% accuracy on Tamil and code-mixed text
2. **Tamil augmentation helps Tamil**: Adding Tamil translations (Exp B) improves Tamil F1 from 0.724 → 0.752
3. **Code-mixed augmentation helps code-mixed**: Adding code-mixed data (Exp C) improves code-mixed F1 from 0.696 → 0.721
4. **XLM-RoBERTa is competitive**: XLM-R slightly outperforms IndicBERT on all languages in the full multilingual setting
5. **Trade-off exists**: Adding multilingual data slightly reduces English-only performance (0.838 → 0.818), which is expected

## ⚠️ Limitations

### Machine Translation

- Tamil translations are machine-generated using IndicTrans2
- Translation quality varies - some tweets may lose nuance or sentiment
- Machine translation errors can introduce label noise (inherited/silver labels)
- A translation quality annotation tool is provided for manual evaluation

### Synthetic Code-Mixing

- Code-mixed tweets are **synthetically generated**, not naturally occurring
- They are explicitly marked as `source=synthetic_codemixed`
- Real code-switching patterns may differ from synthetic mixing

### Domain Mismatch

- The training data consists of US airline tweets in English
- Tamil airline discussion patterns may differ culturally and linguistically
- Limited availability of naturally occurring Tamil airline tweets

### Other Considerations

- Sarcasm detection is challenging across languages
- Slang and informal language may not translate well
- Class imbalance (62.7% negative) affects model behavior
- Results on machine-translated Tamil should **NOT** be directly compared to results on naturally authored Tamil without acknowledging this distinction

---

## 🔬 Research Integrity

- Results are **not fabricated** - they are obtained by running the training scripts on Google Colab
- The model is not claimed to "support Tamil" until actually tested on Tamil data
- Translation quality is not assumed to preserve sentiment without evaluation
- All preprocessing operations are documented and transparent
- Data leakage is verified: **0 leaky IDs** across splits
